# algorithms-playground

Коллекция классических алгоритмов и структур данных на JavaScript. Каждый файл -- самодостаточная реализация с закомментированными примерами вызова.

## Структура проекта

```
src/
  basic/          -- базовые алгоритмы (поиск, Фибоначчи, обходы графов, палиндром и т.д.)
  sorts/          -- сортировки (bubble, insert, merge, quick)
  structure/      -- структуры данных (связный список, хеш-таблица, BST)
  *.js            -- остальные задачи (шифр Цезаря, FizzBuzz, two sum и пр.)
```

## Запуск

```bash
npm install
node src/<файл>.js
```

Вызовы функций в файлах закомментированы -- нужно раскомментировать блок внизу файла перед запуском.

## Линтинг и проверка типов

```bash
npm run eslint          # проверка
npm run eslint:fix      # автоисправление
npm run typecheck       # проверка типов через tsc --noEmit
npm run typecheck:watch # то же в watch-режиме
```

ESLint настроен через `@antfu/eslint-config` (flat config), стиль: 2 пробела, одинарные кавычки, `type` вместо `interface`.

## Алгоритмы

### Сортировки (`src/sorts/`)

#### Bubble Sort

Файл: `src/sorts/bubble-sort.js`

Классическая пузырьковая сортировка. Swap сделан через арифметику (без временной переменной):

```js
array[j] += array[j + 1]
array[j + 1] = array[j] - array[j + 1]
array[j] = array[j] - array[j + 1]
```

Внутренний цикл сокращается на `i` с каждой итерацией (`j < array.length - i - 1`), т.к. максимальные элементы уже "всплыли" в конец.

| Сложность | Время |
|---|---|
| Лучший случай | O(n^2) |
| Средний | O(n^2) |
| Худший | O(n^2) |

> Примечание: данная реализация не прерывает проход при отсутствии обменов, поэтому лучший случай тоже квадратичный.

#### Selection Sort (insert-sort.js)

Файл: `src/sorts/insert-sort.js`

Несмотря на имя файла, реализован **selection sort**: для каждой позиции `i` ищем минимум в оставшейся части массива и ставим его на место.

```js
for (let j = i; j < array.length; j++) {
  if (array[j] < min) {
    min = array[j]
    minIndex = j
  }
}
```

Сложность: O(n^2) во всех случаях.

#### Merge Sort

Файл: `src/sorts/merge-sort.js`

Рекурсивная реализация. Массив делится пополам, каждая половина сортируется рекурсивно, затем сливается через `joinArray`.

Функция `joinArray` работает рекурсивно: на каждом шаге сравнивает головы двух массивов, меньший элемент через `shift()` уходит в `finalArray`. Когда один из массивов пуст, остаток второго дописывается целиком через spread.

Сложность: O(n log n) по времени, O(n) дополнительной памяти.

#### Quick Sort

Файл: `src/sorts/quick-sort.js`

Опорный элемент -- средний по индексу (`array[Math.floor(array.length / 2)]`). Массив разбивается на `lessArray` и `largerArray`, рекурсивно сортируется, результат собирается через spread.

```js
return [...quickSort(lessArray), mediumElement, ...quickSort(largerArray)]
```

Дубликаты опорного элемента отбрасываются (`el != mediumElement`), поэтому при наличии повторов в массиве часть элементов будет потеряна.

| Сложность | Время |
|---|---|
| Средний | O(n log n) |
| Худший (уже отсортированный массив) | O(n^2) |

### Поиск (`src/basic/`)

#### Binary Search

Файл: `src/basic/binary-search.js`

Рекурсивный бинарный поиск на отсортированном массиве. Возвращает найденное значение или `null`. На каждом шаге отсекается половина через `array.slice()`.

```js
if (value < middleValue)
  return binarySearch(array.slice(0, mediumIdx), value)
```

Сложность: O(log n) по количеству сравнений, но O(n log n) суммарно по памяти из-за `slice` на каждом уровне рекурсии.

#### Breadth-First Search (BFS)

Файл: `src/basic/breadth-search.js`

Поиск в ширину на графе, заданном списком смежности (объект, где ключ -- вершина, значение -- массив соседей). Использует очередь (`queue`): достаёт вершину из начала, проверяет соседей, добавляет непосещённые в конец.

```js
let departurePoint = queue.shift()
if (graph[departurePoint].includes(end)) return true
```

Возвращает `true`/`false` -- есть ли путь от `start` до `end`.

> Внимание: нет проверки на посещённые вершины, поэтому на графах с циклами уйдёт в бесконечный цикл.

#### Алгоритм Дейкстры

Файл: `src/basic/shortest-way-Dijctra.js`

Поиск кратчайших путей от стартовой вершины до всех остальных. Граф задаётся объектом вида `{ a: { b: 2, c: 1 }, ... }`, где значения -- веса рёбер.

Алгоритм обходит граф рекурсивно, обновляя `neighbors` (словарь кратчайших расстояний). Если новый путь через текущую вершину короче ранее найденного -- расстояние перезаписывается:

```js
if (((neighbors[start] || 0) + graph[start][point]) < (neighbors[point] || Infinity)) {
  neighbors[point] = (neighbors[start] || 0) + graph[start][point]
}
```

Массив `passed` хранит уже обработанные вершины. Возвращает объект `{ вершина: расстояние }`.

### Числа и последовательности

#### Fibonacci (наивная рекурсия)

Файл: `src/basic/fibonacci.js`

Прямая рекурсивная реализация. `fibonacci(0) = 0`, `fibonacci(1) = 1`.

Сложность: O(2^n) -- экспоненциальный рост из-за повторных вычислений.

#### Fibonacci (с мемоизацией)

Файл: `src/basic/fibonacci-memorized.js`

Содержит три варианта:

1. **Рекурсия с внешним store** -- `fibonacciMemorized(num, store)`. Передаёт объект-кеш вторым аргументом, перед рекурсивным вызовом проверяет `store[num]`.

2. **Итеративная версия через стек** -- `fibonacci(n)`. Использует массив `orderFib` как стек: вместо рекурсии кладёт `n-1` и `n-2` в стек, суммирует единицы при достижении базового случая.

3. **Декоратор `cacheDecorator`** -- универсальная обёртка для мемоизации любой функции. Ключ кеша формируется через `args.join('-')`.

```js
function cacheDecorator(fn) {
  const cache = {}
  return function (...args) {
    const key = args.join('-')
    if (cache[key]) return cache[key]
    const result = fn(...args)
    cache[key] = result
    return result
  }
}
```

#### Решето Эратосфена

Файл: `src/sieve-of-eratosthenes.js`

Находит все простые числа до `n`. Создаёт массив `[2..n]`, затем для каждого `i` от 2 до `sqrt(n)` помечает кратные `i` (начиная с `i^2`) как `false`:

```js
if (index + 1 >= i ** 2 && num % i == 0) return false
```

Финальная фильтрация убирает помеченные элементы. Сложность: O(n log log n).

### Строки и прочие задачи

#### FizzBuzz

Файл: `src/fizz-buzz.js`

Классика. Для чисел от 1 до `num`: кратные 3 и 5 -- "FizzBuzz", только 3 -- "Fizz", только 5 -- "Buzz", остальные -- само число. Проверка на делимость обоим идёт первой (чтобы не перехватилась отдельными проверками на 3 или 5).

#### Caesar Cipher

Файл: `src/caesar-cipher.js`

Шифр Цезаря со сдвигом `num`. Работает с обоими регистрами: определяет регистр через `symbol == symbol.toUpperCase()`, сдвигает в пределах `a-z` через `charCodeAt` / `fromCharCode` с модулем 26, затем приводит обратно к нужному регистру.

```js
String.fromCharCode((symbol.charCodeAt(0) - 97 + num) % 26 + 97)
```

Пробелы сохраняются (разбиение по пробелам и обратная склейка через `join(' ')`).

#### Palindrome

Файл: `src/basic/palindrom.js`

Проверяет, является ли строка палиндромом. Перед сравнением приводит к нижнему регистру и фильтрует только буквы `a-z` (убирает пробелы, знаки препинания). Затем сравнивает строку с её `reverse()`.

```js
line.join('') == line.reverse().join('')
```

#### Reverse Words

Файл: `src/reverse-words.js`

Разворачивает строку целиком (не отдельные слова, а всю последовательность символов).

#### Reverse Array In Place

Файл: `src/reverse-array-in-place.js`

Разворачивает массив, обменивая элементы с двух концов. Формально создаёт новый массив (`newArray`), а не модифицирует исходный in-place.

#### Two Sum (collect-sum.js)

Файл: `src/collect-sum.js`

Находит все пары элементов массива, дающие в сумме `sum`. Строит словарь частот (`originDict`), затем для каждого элемента проверяет наличие дополнения `sum - digit`. Найденные пары добавляются в `results`, соответствующие счётчики в словаре уменьшаются.

```js
collectSum([1, 5, 2, 3, 4, 7, 6, 5], 9)
// => [[2,7], [3,6], [4,5], [7,2], ...]  (с дубликатами)
```

#### Harmless Ransom Note

Файл: `src/harmless-ransom-note.js`

Проверяет, можно ли составить `noteText` из слов `magazineText`. Строит частотный словарь слов журнала, затем вычитает слова записки. Если хоть одного слова не хватает -- `false`.

#### Mean, Median, Mode

Файл: `src/mean-medium-note.js`

Вычисляет три статистических показателя для массива чисел:

- **Mean** -- среднее арифметическое (через `reduce`, с `toFixed(2)`)
- **Median** -- серединное значение (для нечётной длины -- центральный элемент, для чётной -- среднее двух центральных)
- **Mode** -- самый частый элемент(ы). Если все встречаются одинаково, мода не определена (`maxFrequency = null`, но массив значений всё равно возвращается)

#### Max Profit

Файл: `src/max-profit.js`

Задача "Best Time to Buy and Sell Stock". За один проход находит максимальную прибыль: отслеживает минимальную цену покупки и максимальную разницу с ценой следующего дня.

#### Island Perimeter (matrix-perimeter.js)

Файл: `src/basic/matrix-perimeter.js`

Подсчёт периметра фигуры в бинарной матрице. Каждая клетка со значением `1` даёт 4 стороны, смежные клетки уменьшают периметр на 2 (убирается общая граница). Проверяются соседи справа и снизу.

## Структуры данных (`src/structure/`)

### Linked List (двусвязный список)

Файл: `src/structure/linked-list.js`

Конструкторная функция `LinkedList` с указателями `head` и `tail`. Узел (`Node`) хранит `value`, `next`, `prev`.

Методы:
- `addToHeadList(value)` -- вставка в начало
- `addToTailList(value)` -- вставка в конец
- `removeFirstNode()` -- удаление из начала, возвращает значение
- `removeLastNode()` -- удаление с конца, возвращает значение
- `listHasValue(value)` -- линейный поиск, `true`/`false`
- `indexOf(value)` -- возвращает массив индексов всех вхождений

### Hash Table

Файл: `src/structure/hash-table.js`

Хеш-таблица с цепочками (chaining). `HashTable(size)` создаёт массив бакетов заданного размера.

Хеш-функция -- сумма `charCodeAt` всех символов ключа, взятая по модулю размера:

```js
hash += key.charCodeAt(i)
return hash % this.bucketSize
```

Коллизии (напр. анаграммы "Dane", "Daen", "Dnae") обрабатываются через цепочки -- `HashNode` содержит указатель `next`.

Методы:
- `insert(key, value)` -- вставка/обновление
- `get(key)` -- поиск по ключу
- `retrieveAll()` -- возвращает массив всех пар `"key : value"`

### Binary Search Tree (BST)

Два варианта реализации:

#### Вариант 1: конструкторная функция (`src/structure/binary-tree.js`)

`BST(value)` -- узел с `left` и `right`. Методы через `prototype`:

- `insert(value)` -- вставка (>= идёт вправо, < влево)
- `contains(value)` -- проверка наличия
- `depthTraversal(iterator, typeOrder)` -- обход в глубину:
  - `'pre-order'` -- корень, левое, правое
  - `'post-order'` -- левое, правое, корень
  - `'in-order'` (default) -- левое, корень, правое (по возрастанию)
- `breadthTraversal(iterator)` -- обход в ширину (по уровням)
- `getMinVal()` -- минимум (крайний левый лист)
- `getMaxVal()` -- максимум (крайний правый лист)

#### Вариант 2: классы ES6 (`src/structure/binary-tree2.js`)

`BinaryTree` с классами `NodeTree`. Узел хранит `childs: { left, right }`.

- `add(value)` -- вставка (< влево, >= вправо)
- `print()` -- обход в глубину (DFS) с использованием очереди (`unshift`), возвращает строку значений
